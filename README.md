# 해커톤 작품 갤러리

후드티 QR 코드로 여는 학생 작품 갤러리입니다.
QR을 찍으면 매트릭스 스타일 모션 인트로가 나오고, "갤러리 입장하기"를 누르면 갤러리가 열립니다.
학생들은 보기만 합니다(직접 올리는 기능은 없습니다). 학생 실명은 어디에도 넣지 않고, 모둠 번호(또는 팀명)만 표시합니다.

## 구조 한눈에 보기

- **이 저장소(GitHub Pages)**: 갤러리 화면(정적 페이지). 주소가 고정이라 QR을 다시 뽑을 일이 없습니다.
- **Google Apps Script** (`apps-script/Code.gs`): 시트를 읽어 데이터를 JSON으로 건네주는 역할만 합니다.
- **Google 시트**: 선생님이 모둠·제목·소개·링크만 붙여넣는 곳. 저장하면 갤러리에 바로 반영됩니다. 시트 파일 자체는 비공개로 유지하세요.

## 처음 한 번만 하는 설정 (약 10분)

1. **시트 만들기**: 새 Google 시트를 만들고 첫 탭 이름을 회차 이름(예: `2026-1회`)으로 바꿉니다.
   1행에 `모둠 | 제목 | 한줄소개 | 작품링크 | 썸네일링크(선택)` 헤더를 적습니다.
   같은 시트에 탭을 하나 더 추가해 이름을 `소개`로 짓습니다. A1=소개 문구, A2=대회 이름(예: `1st SCH Hackathon`), A3=날짜(예: `2026.10.24 토요일`), A4=장소(예: `컴퓨터실`), A5=시간(예: `09:00-17:00`). A2~A5는 인트로 화면에 표시되며, 다음 회차 때 내용만 바꾸면 됩니다.
   선택: `설명` 탭을 만들면(A열=제목, B열=내용, 한 줄이 한 장) 인트로 다음에 나오는 설명 슬라이드를 직접 고칠 수 있습니다. 탭이 없으면 기본 슬라이드가 나옵니다.
2. **Apps Script 붙여넣기**: 시트 메뉴 → 확장 프로그램 → Apps Script → 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
   코드 맨 위 `SHEET_ID`에 시트 주소 가운데 긴 문자열을 넣습니다.
3. **웹앱 배포**: Apps Script 오른쪽 위 배포 → 새 배포 → 유형 "웹 앱" →
   실행 사용자 "나", 액세스 권한 "모든 사람" → 배포 → 권한 승인(내 계정 선택 → 고급 → 이동 → 허용).
   나온 웹 앱 URL(`.../exec`)을 복사합니다.
4. **주소 연결**: 이 저장소의 `index.html` 맨 위 `API_URL`에 방금 복사한 `/exec` 주소를 붙여넣고 커밋합니다.
   (GitHub 웹에서 index.html → 연필 아이콘으로 바로 수정해도 됩니다)
5. **확인**: 갤러리 주소 `https://본인아이디.github.io/hackathon-gallery/` 를 열어 인트로와 갤러리가 보이는지 확인합니다.
   이 주소가 후드티 QR에 들어갈 영구 주소입니다. (인트로는 같은 탭에서는 한 번만 나오고, "건너뛰기"로 바로 들어갈 수도 있습니다.)

## 평소 운영

- **작품 등록/수정**: 시트 셀만 고치면 됩니다. 갤러리는 열 때마다 시트를 새로 읽습니다.
- **모둠 카드**: 1번~10번 자리 카드는 항상 자리를 잡고 있습니다. 시트의 i번째 줄이 i번 자리 카드이고(줄 순서 = 자리), 모둠 이름 칸을 바꾸면 갤러리에도 바로 반영됩니다. 링크가 아직 없는 자리는 "준비 중"으로 보이다가, 링크를 넣는 순간 작품 카드로 바뀝니다.
- **다음 해커톤**: 시트에 새 탭(예: `2027-1회`)을 추가하고 작품을 채우면 끝.
  갤러리는 최신 탭을 기본으로 보여주고, 이전 회차는 상단 버튼으로 전환합니다. QR은 그대로입니다.
- **모둠 표시**: 시트에 쓴 그대로 나옵니다. "3모둠"이든 팀 이름이든 상관없고, 학생 개인 이름은 넣지 마세요.

## 개인정보 체크리스트

- 갤러리·시트·이 저장소 어디에도 학생 실명을 넣지 않습니다.
- 링크된 작품 안도 확인하세요: 유튜브 채널명, 영상 속 얼굴·이름표 등으로 학생이 식별되지 않아야 합니다.
- 작품의 외부 공개에 대한 학생·학부모 동의와 학교 지침을 먼저 확인하세요.
- "모든 사람" 공개는 주소를 아는 누구나 볼 수 있다는 뜻입니다. 공개되어도 되는 내용만 올립니다.

## QR 인쇄 팁

- 갤러리 주소(`https://본인아이디.github.io/hackathon-gallery/`)로 QR을 만들 때 오류 정정 수준 H, 인쇄 크기 3cm 이상을 권장합니다.
- 검정 QR + 흰 바탕처럼 명암 대비가 뚜렷해야 하고, 자수로는 스캔이 잘 안 되니 인쇄(실크스크린/DTG)를 권장합니다.
- 단축 URL(bit.ly 등)을 거치지 마세요. 서비스가 바뀌면 후드티 QR이 죽습니다.
